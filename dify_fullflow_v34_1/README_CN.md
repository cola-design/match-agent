## 保留的 V34 修正

- 唯一、位置相符的 PC/CB 级标记关联到 ATS，并补入选型参数；支持原生文字把 PC/CB 和“级”拆成相邻文字段的情况。多个适用目标或参数冲突继续提问，不推断 ATS 极数。
- 明确的“时间控制器/时控开关”按时控功能分类。接触器位号结合原生支路位置核对；时控功能与相邻接触器形成回路关系候选，仍要求人工核对控制关系与完整采购规格，不代替接线设计。
- 已取得独立符号证据的变压器不再出现在“符号未核实”的待处理列表。已解决观测保留在结果的解决记录中；不把真正的分类、保护或参数冲突一并清掉。
- 局部视图问题带页码、视图和裁切范围。仅当定点任务全部指定目标已取得独立证据时关闭该项定点提示；普通局部读取不完整、不可读和缺页问题继续保留，不按文字数量宣称整页准确。
- 修复多页流程的二次索引：原生文件选择节点已取出当前页后，地址适配器只接收这一份文件，不再按全局页序号重复索引。若选择结果数量不对，明确停止，不能以第一页替代。

## 确认表怎么填

只改黄色格，不删行、不改表头，不使用公式；物料编码按文本填写。

1. **识图与问题清单**：核对类别、型号、柜组和回路；填写实际单柜数量、单位、供货范围、厂商或“未指定”，核实后确认填“是”。本页不再要求编辑参数 JSON。误识别行填 EXCLUDE 并写依据；正常保留 KEEP。
2. **技术参数确认**：已知参数自动填入电流、极数、脱扣曲线、剩余动作电流、分断能力、电压、容量、ATS 类别等中文列。正确的保留；更正时填实际值。未知留空，不用 0 代表未知。数值列不带单位，一次/二次电压成对填写。其他要求用普通文字；系统未映射的原参数只读保留。
3. **待确认问题**：逐项核对真实疑点，处理结论填“已核对”，写具体结果、资料或图纸修订依据。只填整体确认不能绕过未解决问题。ATS 极数仍为空、剩余电流器件订货类别仍笼统等情况不能只靠一句“已核对”跳过。无法确定时保留待确认，不提交为批准。
4. **柜组数量**：填写实际柜体数量。单柜用量乘此处数量形成总量，不能把总量重复填入单柜数量。柜号数量不自动等于柜体数量。
5. **线路参考_默认不报价**：未由我方采购的保持“否”，不用填长度或逐行确认。合同确需我方供货的改“是”，填写实际单柜采购用量、纳入依据和确认。多根布电线应核对合计采购米数；不能按电缆芯数重复计算电缆长度。
6. **手工补录**：有漏项才用；新增器件的技术参数在相同行 ID 的参数行填写。不用的保持原样。
7. **完整性确认、填写说明**：完成全部核对后写实际完整性结论、确认和确认人。未完成局部复核时不能把整体确认作为通过依据。

保存 XLSX，在同一 Dify 对话上传，点击“提交问题清单”。确认表会验证项目、版本、固定内容、参数、行 ID 和问题答复。人工核对依据保存在项目记录和排产技术原文中。

正式采购前仍需核对数据库候选、厂家规格和适用技术要求。“其他技术要求”会作为要求文字传递并保留，产品 API 是否能按这些要求筛选取决于现有 API，不能据此宣称所有特殊功能已自动验证。

## 保留的业务

PDF 与可选技术协议 → 图纸及问题确认 → 数据库选型 → 选型确认 → 采购报价表 → 报价确认回传 → 排产技术资料表格。

六项入口保持：开始选型、提交问题清单、提交选型确认、提交报价表、查看项目、生成排产资料。DWG 本版仍未接入。

柜外或供货范围未明确的线路默认仅作参考，不自动进入产品查询、采购数量或报价金额。明确柜内线路保留核对；柜内接线、母排等实际成本仍需工艺定额或人工补录，本版未自动核算完整布线成本。合同责任以合同和人工确认范围为准。

## 验证与能力边界

`validation_v34_1.json` 汇总本地验证：

- 原生 PDF、文字位置、旋转、回路、矢量变压器证据、分类、参数、范围、签名回传及中文字段测试。
- 最新实际上传清单与对应原生位置重放，检查已发现的错误；发布只含汇总，不包含客户文件。
- 官方 Dify 1.8.0 的生产结构导入、浏览器编辑页，以及真实运行引擎测试。
- 模型测试回复故意漏掉变压器、把时控器误分为控制器；验证规则修正与真实冲突保留。
- 多页、不同方向、同型号不同位置的受控 PDF 运行检查，验证页图选择和独立位置。
- 未解决问题的回传被拒绝且没有触发产品查询；填写工程师依据后允许进入选型。
- 中文参数回传、选型确认、报价确认和排产输出完整链路；参考线路不计价。

本地模型与产品服务为受控测试数据，真实千问调用和公司数据库访问为零。上述测试验证程序行为与已知错误处理，不是任意电气图纸的准确率保证；真实模型输出仍需公司内网复测和工程师确认。

当前每批最多 12 页、100 项识图候选，定点补漏每页最多 24 处，原生 PDF 读取预算 10 MB。加密、不支持的文字编码、扫描件和超预算内容明确提示或降级，不能把部分结果当成完整识别。

发布白名单只包含通用 YML、源码、通用测试、说明与验证汇总；不含客户 PDF/XLSX、原始模型回复、签名上下文、环境配置和凭证。
