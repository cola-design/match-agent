# V33：把识图、供货范围与采购报价分开确认

下载 `downloads/cabinet_project_v33.yml`，导入 Dify 1.8 后新建对话，沿用当前模型、插件和环境变量，上传完整 PDF，发送“开始选型”。旧对话的确认表不要回传到新项目。R2 是项目修订号，不是应用版本。

继续使用 qwen3-vl-plus、已安装的 Base64 1.1.0 与 PDF-to-Images 1.0.1。无需新增插件、PDF 解析 API 或另部署服务器。

## 线路是否应报价

线缆的性能代号不决定合同供货范围。WDZB 是无卤、低烟、阻燃 B 类的性能标记；BYJ/YJY 是线种；SC/JDG/CT、WC/CC 等是穿管、桥架或敷设标注。不能把整条标注当成一个断路器型号，也不能从线路截面推算采购长度。

- 明确写“柜内接线”等、且没有内外范围矛盾的线路，保留在主清单核对。
- 柜外、建筑敷设或供货范围未明确的线路，默认进入“线路参考_默认不报价”。图面文字、解释、回路和原图位置保留；不会默认查询产品或进入报价金额。
- 默认“否”的参考行无需填写采购用量、厂商和确认。参考中的疑点不再要求作为器件选型前置条件逐项消除；工程师仍须核对项目供货范围与完整性。
- 若合同实际包含这些线路，在参考表将“是否由我方采购并计价”改成“是”，填写归属柜组、实际单柜采购用量、厂商或“未指定”、采购方式、纳入依据，并确认。纳入后沿用正常选型、报价与审批流程。
- BYJ 多根电线需确认各规格的实际采购米数；电缆多芯不等于按芯数重复计算电缆长度。本版不自动测量长度，也不从图面编号推断数量。单位统一为 m；用量按单柜，BOM 再乘已确认柜体数量。
- 不计价参考行保存在项目和最终报价、排产文件的参考页中，不混入采购数量或金额；合同责任以人工确认和合同为准。
- 柜内电线、母排等实际成本仍需按工艺定额核对或补录。本版没有自动计算完整的柜内布线成本。

## 原生矢量辅助核对变压器

原生文字只证明电压比、VA 等标记存在，不能单独证明器件类别。本版在原生 PDF 中另外读取闭合三次曲线，联合核对两个重叠圆形绕组、实际描边引线、附近电压比与 VA 容量；证据唯一时补充为变压器候选，并保留核对记录。

使用尺寸、比例和相对位置规则，不固定某张图的电压、容量、位置或回路数量。无引线、无容量、多个容量有歧义、字体轮廓及不可见路径不作为此项自动分类证据。其他画法、扫描件或不支持的原生内容继续走视觉与人工核对，不承诺所有符号都可由该规则识别。采购数量仍为空，须人工确认。

## 继续保留的校验与业务

- 参数按器件类别使用：变压比和 VA 不写进邻近 MCB；PC/CB 类别用于 ATS；MCB 与独立 mA 标记冲突继续提出核对，不擅改 RCBO。
- 功能符号不直接建采购行；独立位置的同型号器件不按文字去重。实际出线编号、回路成员与负荷重新核对；来源、相别及线路片段另存注释。
- 保留原生文字定位、整页概览、实际局部裁切、定点补漏、扫描件降级与失败记录。未覆盖或不确定内容继续可见。
- 确认表保护原图文字、固定列、项目和版本；不得直接删行。误识别用 EXCLUDE 和依据，漏项用人工补录。
- 业务：PDF 与可选技术协议 → 识图及问题核对 → 数据库选型 → 选型确认 → 采购报价表 → 报价确认回传 → 排产技术资料表格。
- 保留六项入口：开始选型、提交问题清单、提交选型确认、提交报价表、查看项目、生成排产资料。DWG 出图暂不纳入。

`DIFY_FILES_BASE_URL` 沿用插件能访问的 Dify 附件根地址；`MONGODB_API_BASE_URL` 沿用既有只读产品 API 根地址。YML 不含公司地址、MongoDB 连接串或密钥。接口不可访问时明确报错，不用虚构产品替代。

## 本地验证与边界

详细汇总见 `validation_v33.json`。

- 原生 PDF、位置与回路、最终证据、供货范围和签名 XLSX 回传回归；包含不纳入、明确纳入、缺用量、固定列篡改、仅参考项目等情况。
- 实际上传清单与原始 PDF 的本地重放：核对变压器候选、独立器件位置、出线数量、真实冲突保留、主清单与线路参考分区。仅发布汇总，不发布客户文件。
- 官方 Dify 1.8.0 编辑页与运行引擎测试。测试模型故意漏掉全部变压器回复并注入部分错误关联；检查原生证据补充、表格下载和错误约束。
- 含柜外线路的受控 PDF 走完问题表、选型表、报价表回传及排产输出；参考行未进入查询或金额，最终文件保留未计价参考页。

本地模型和产品服务为受控测试数据，真实千问调用和公司数据库访问均为零。测试证明流程和已知校验的行为，不代表真实千问对任意电气图的完整识别准确率；仍需公司内网复测并人工确认关键参数、数量和供货范围。

当前每批最多 12 页、100 项识图候选，定点补漏每页最多 24 处；原生解析限制 10 MB、每页 3500 文字段及其他解压预算，具体以节点提示为准。超预算明确提示，不能把截断结果当完整项目。

发布白名单只含通用 YML、源码、通用测试、说明和验证汇总；不含客户 PDF/XLSX、原始模型回复、签名上下文、环境配置和凭证。
