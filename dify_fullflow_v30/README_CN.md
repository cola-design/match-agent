# V30：整图统一核对后再生成确认清单

本版修复多个裁图的观测被累加为器件、残缺型号进入选型、线缆文字被当回路号，以及电压比与断路器型号拼接的问题。

## 使用

导入 `cabinet_project_v30.yml`，新建对话，用同一份完整 PDF 发送“开始选型”。旧 R2 确认表属于旧会话，不要回传到新项目。模型沿用通义接入的 `qwen3-vl-plus`，插件沿用工作区已安装的 PDF-to-Images 1.0.1、Base64 1.1.0；不需要重新安装，也不需要修改服务器。

环境变量沿用现有配置。`DIFY_FILES_BASE_URL` 用于插件读取 Dify 附件，默认标准 Docker 内网 `http://api:5001`，该地址需要插件实际可达；部署不同请沿用此前已经成功的值。`MONGODB_API_BASE_URL` 是既有只读产品 API 根地址，不是 MongoDB 连接串。YML 不包含地址或密钥。

保留六项操作：开始选型、提交问题清单、提交选型确认、提交报价表、查看项目、生成排产资料。采购报价表确认回传后生成排产表格；本版不生成 DWG。

## 识图方法

1. 原页概览与六个局部图先分别识读。裁切保留原像素颜色，不伪造原生文字坐标。
2. 新增一次完整有效图面复核：真实裁去空白边，带上局部文字提示，重新定位独立符号、完整型号、实际印刷回路号与连接关系。
3. 只有这次整图核实的实体建立候选清单。局部观测保留作证据，不能累加采购数量。提示中不传局部模型坐标，以免当作定位答案。
4. 裁断词、端口相别、变压器与断路器拼接标注单列复核。柜号、相别、线缆规格不能充当回路号。不同位置的同型号器件仍分别保留。
5. 对原生文字出现次数与整图实体候选检查双向差异；出现次数不是采购数量，程序不按次数补造或删除器件。
6. 电压比出现但缺少对应独立变压器候选时明确提示复核，不把电压比拼进断路器型号。VA 参数只能关联变压器。
7. 整图复核失败或明确未读完时，不生成可用于选型的确认表，也不覆盖原项目状态。

没有使用电梯图专属的固定器件数量、固定回路编号或型号替换规则。每页增加一次模型调用，运行时间会增加。整图复核仍依赖视觉模型，不保证零漏识；无法在整图确认的局部读法在“识图待复核”中保留，必须核对漏项。
