# V34.2：明确确认表的提交入口

当前已有项目可以继续在原对话使用：下方聊天输入框旁的回形针或＋号添加一份 XLSX，在同一条消息输入对应命令再发送。

| 当前文件 | 提交命令 |
| --- | --- |
| 识图与问题确认清单 | 提交问题清单 |
| 数据库匹配后生成的 BOM 选型确认表 | 提交选型确认；本版也支持提交BOM表 |
| 采购报价确认表 | 提交报价表 |

也可以发送“提交”，流程会按当前阶段处理附件。每次只传一份当前版本的 XLSX。顶部 PDF 输入用于首次传图和可选技术协议；后续确认表从聊天附件提交。

本版修改：

- 在开场说明、当前阶段提示和每份确认表的回复中明确“上传位置、文件类型、命令、同一条消息发送”。
- 将选型确认文件名改成“BOM选型确认表”，保留原选型确认数据结构。
- 支持提交问题确认清单、提交BOM表、提交bom表、提交 Bom 表等大小写和空格形式。
- 保留六项原入口。跨阶段、无附件、错格式和一次上传多份表仍明确提示，不按错误阶段审批。
- 识图模型、业务图的节点和连线、PDF/XLSX 上传配置沿用 V34.1。

导入 YML 后需使用你原来的模型和环境变量配置。当前已经生成的确认表，应在生成它的原项目对话回传；新建应用或新项目不继承旧项目会话签名。

本地执行发布 YML 内真实代码，验证 8 组提交、提示和文件名检查，另核对图结构、模型设置及附件配置保持一致。本版没有重新调用公司模型或公司 API，不声称重新验证电气图识别准确率。

发布只含通用 YML、构建脚本、测试与说明，不含客户 XLSX、PDF、原始模型回复、签名上下文、地址或密钥。
